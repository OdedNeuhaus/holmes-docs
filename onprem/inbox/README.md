# inbox/

זורקים לכאן **כל דבר** שצריך להפוך לתיעוד: הערות, קבצי txt, צילומי מסך, קבצי YAML, JSON של דשבורד, פלט של פקודות, מסמך Word מיוצא...

אחר כך מבקשים מ-Claude:

```
/add-docs
```

Claude יקרא את מה שיש כאן, ישאל איפה זה צריך להיכנס, ויהפוך את זה לעמוד מסודר תחת `docs/`.

> כל מה שבתיקייה הזו (חוץ מהקובץ הזה) **לא נכנס ל-Git** ולא לאתר, כדי שהערות גולמיות וסודות לא ידלפו בטעות.
